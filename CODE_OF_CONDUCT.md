# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community.
Participants should communicate professionally, assume good intent, give useful
feedback, and respect different experiences and backgrounds.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, sexualized language or attention, publishing private information, and
other conduct that would be inappropriate in a professional setting.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or
restrict participation when this code is violated. Reports should be sent
privately to the maintainers listed in `MAINTAINERS.md` rather than discussed in
public issue threads. Reports will be handled as confidentially as practical.

This code of conduct is adapted from the Contributor Covenant.
