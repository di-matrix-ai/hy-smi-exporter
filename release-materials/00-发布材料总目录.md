## 4 放行规则

只有在下列条件全部满足后，才能将材料称为“正式 `v1.0.0` 发布终版”：

1. `make release-check` 无占位符错误；
2. `BUILD_INFO.md` 与 Git tag、CI 和产物一致；
3. 真实设备测试、兼容矩阵和指标语义已由鼎茂确认，外部技术意见已如实记录；
4. 海光反馈的 K100_AI 字段问题和多卡耗时控制已完成候选版本复测；
5. 技术协作和公开发布边界已留档，对外材料不暗示海光官方授权或认证；
6. 首版容器场景明确不纳入兼容和发布范围；
7. 已确认公开仓库不包含内部表单、个人联系方式或其他仅供双方留档的内容，并在需要时使用清理后的公开历史；
8. `07-release-approval.md` 已由鼎茂有权人员确认；
9. Release Notes 和公告不再包含 `TBD`、`<待填写>` 或示例地址。
