- 正式 commit、tag、CI 链接、二进制和校验值。

## 4 放行规则

只有在下列条件全部满足后，才能将材料称为“正式 `v0.1.0` 发布终版”：

1. `make release-check` 无占位符错误；
2. `BUILD_INFO.md` 与 Git tag、CI 和产物一致；
3. 真实设备测试、兼容矩阵和指标语义已由双方确认；
4. 海光公开授权范围已书面留档；
5. 首版容器场景明确不纳入兼容和发布范围；
6. 已确认公开仓库不包含内部表单、个人联系方式或其他仅供双方留档的内容，并在需要时使用清理后的公开历史；
7. `07-release-approval.md` 已由双方授权人员确认；
8. Release Notes 和公告不再包含 `TBD`、`<待填写>` 或示例地址。
