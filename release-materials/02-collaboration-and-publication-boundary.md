# 技术协作及公开发布边界说明

本文件用于明确 `hy-smi-exporter` 的项目责任、技术协作方式和公开内容边界，
作为项目发布、维护和社区沟通的统一依据。

- 项目开发、代码权属确认、GitHub 仓库管理、版本维护和公开发布责任主体：
  **上海鼎茂信息技术有限公司（Shanghai Ding Mao Information Technology Co., Ltd.）**；
- GitHub 仓库：`https://github.com/di-matrix-ai/hy-smi-exporter`；
- 开源协议：Apache License 2.0；
- 上海鼎茂信息技术有限公司负责项目技术决策、Pull Request 合并、兼容性结论、
  Release 发布和社区维护；
- 相关设备厂商技术人员及其他社区贡献者可以个人身份参与测试、技术建议、
  Issue、Pull Request 和代码审阅；
- 个人技术协作不代表其所在单位作出授权、认证、支持承诺或质量担保；
- `hy-smi-exporter` 是一款支持海光 DCU / HCU 设备指标采集和 Prometheus 监控接入的开源项目，不是海光官方产品。

## 2 公开内容边界

- 本项目引用了海光驱动及 `hy-smi` 命令集，依托于海光驱动及 `hy-smi` 命令集；
- 本项目不分发海光驱动、固件或 `hy-smi` / `hcu-smi` 二进制；
- 厂商驱动兼容表不是 exporter 兼容承诺；
- 指标字段缺失或工具输出变化时，可能导致部分指标不输出；
- 生产环境应限制 `/metrics` 访问，并避免公开序列号、Unique ID、主机名和 PCIe 地址。

## 4 不公开内容

下列内容不得放入公开仓库、Issue、Pull Request、Release 或发布公告：

- 未取得分发权的驱动、固件、DTK、`hy-smi` / `hcu-smi` 二进制和商业资料；
- 设备序列号、Unique ID、真实主机名、内部 IP、PCIe 地址和客户信息；
- 密码、Token、SSH 私钥、内部账号和内部链接；
- 未经验证的兼容性结论、发布日期、路线图或支持承诺；
- 未公开漏洞、内部测试原始数据和个人联系方式；
- 容易被理解为海光官方授权、官方认证、联合发布或质量担保的表述。

## 5 PR 与发布决策

- 普通代码和文档 PR：CI 通过并取得上海鼎茂信息技术有限公司维护者批准后合并；
- 设备适配和厂商字段 PR：可以邀请技术协作者审阅，但其意见不作为强制合并门槛；
- 指标名称、类型、单位和标签：由上海鼎茂信息技术有限公司维护者最终决定；
- 兼容性结论：由上海鼎茂信息技术有限公司根据可追溯测试证据发布；
- GitHub Release、社区公告及 Prometheus exporter 目录 PR：由上海鼎茂信息技术有限公司负责审批和执行。
