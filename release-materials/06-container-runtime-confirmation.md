# 容器运行方式确认单（首版不适用）

## 结论

根据当前发布范围，`v0.1.0` 不兼容、不测试、不发布 Docker、Docker Compose、Kubernetes 和容器镜像。本文件仅用于记录后续版本是否重新纳入容器场景，不构成首版发布前置条件。

当前公开镜像只包含 `hy-smi-exporter`，不包含海光驱动、固件、`hy-smi` / `hcu-smi` 和厂商运行库。仅映射 `/dev/kfd`、`/dev/dri` 不能保证厂商工具能够在容器内执行。

Docker Compose 和 Kubernetes 文件仅作为后续版本配置模板，不能宣称为 `v0.1.0` 已验证部署方案。

## 1 首版结论

最终选择：`首版不支持容器，后续版本另行评估`

## 3 安全检查

- [ ] 厂商工具和运行库具备容器使用及分发授权；
- [ ] 未把宿主机整个 `/usr` 或 `/lib` 目录写入挂载；
- [ ] 厂商工具和依赖以只读方式提供；
- [ ] 已评估是否可取消 `privileged`，改为设备和 capability 最小授权；
- [ ] `/metrics` 端口已限制访问范围；
- [ ] 镜像中不包含客户数据、凭据、驱动安装包或商业授权文件。
