## 2 提交前检查

- [ ] 公开仓库无需登录即可访问；
- [ ] Apache-2.0 许可证、源码和 README 完整；
- [ ] 至少一个公开 Release 可下载；
- [ ] 维护者和 Issue 渠道有效；
- [ ] 兼容范围和已知限制明确；
- [ ] PR 描述只陈述项目事实，不使用“官方认证”“官方支持”等表述；
- [ ] 项目命名和链接与正式仓库一致。
- [ ] 提交 commit 包含有效的 DCO `Signed-off-by`；
- [ ] 默认端口已在仓库公开后完成冲突复核和必要登记。
