## 2 已确认的环境事实

- 系统：Kylin Linux Advanced Server V10，Linux amd64；
- 已记录内核：`4.19.90-89.11.v2401.ky10.x86_64`；
- 设备：至少一个节点为 BW100 × 2，Device ID `0x6370`；
- 驱动：`6.3.28-V1.3.0b`；
- VBIOS：`6.312.002400Q.984889`；
- 厂商工具：`/opt/hyhal/bin/hy-smi`；
- 构建环境：`go1.23.12 linux/amd64`；
- 部署目录：`/data/exporter`；
- 服务管理：systemd；
- Prometheus：Docker 部署，15 秒抓取周期。

## 3 已确认的测试结果

- `go test ./...`、`go vet ./...` 和 `go build` 通过；
- `hy-smi -a --json` 在该环境不返回可解析 JSON，文本回退路径验证通过；
- 两个节点均识别 2 张设备；
- `/healthz` 返回 `ok`；
- 温度、功耗、电压、时钟、PCIe、VRAM/GTT 和设备身份指标可输出；
- 单卡显存总量为 `68702699520` bytes；
- Prometheus 抓取目标确认 `UP`；
- systemd 运行记录中，服务内存约 12.2 MiB；
- 节点 A 存在约 1 天 22 小时的连续服务运行观察记录。

## 4 不能由历史证据确认的内容

- 当时源码对应的 Git commit；
- 准确 DTK 和 `hy-smi` 工具版本号；
- 所有 RAS/ECC/坏页指标与厂商原始值的逐项对照；
- 异常场景测试，包括驱动未加载、权限不足、工具缺失和命令超时；
- 完整抓取次数、成功率、平均和 P95 采集耗时；
- 当前候选 commit 的端口、指标命名、单位和标签行为。

## 5 发布使用规则

1. 历史证据可以证明项目已完成真实设备适配，不要求重新进行完整测试。
2. 兼容矩阵只能在当前候选 commit 完成短回归后标记为“已验证”。
3. 两张原始截图不能直接上传公开仓库，必须遮盖 IP、主机名和其他资产信息。
4. 不以本记录表达设备厂商官方认证、官方支持或质量担保。
5. 当前版本回归通过后，将新 commit、运行时间、脱敏 `/metrics` 和日志追加到主报告。
