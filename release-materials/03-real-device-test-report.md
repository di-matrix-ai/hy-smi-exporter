## 5 与当前候选版本的差异

历史测试版本与当前候选版本至少存在以下差异：

- 默认端口从 `9393` 调整为候选端口 `9584`；
- `hy_smi_devices_total` 已调整为 `hy_smi_devices`；
- exporter 不再自行生成 `instance` 标签，由 Prometheus 添加；
- 百分值指标调整为 0 至 1 的 ratio；
- 时钟指标由 MHz 调整为 Hz；
- RAS、字节换算和并发抓取逻辑已修正。

后续重新取得海光机器或兼容测试环境时，建议针对当前或后续版本执行以下短回归，无需重做完整适配：

1. 启动当前候选二进制并记录 commit；
2. 确认 `/healthz` 和 `/metrics` 正常；
3. 确认 `hy_smi_devices=2`；
4. 抽查温度、功耗、显存、时钟和 PCIe；
5. 确认 Prometheus 以 15 秒周期连续抓取至少 30 分钟；
6. 保存脱敏输出和日志，并记录无错误或对应问题单。

## 6 兼容性结论

历史组合结论：BW100 已在当时工作区版本完成真实设备采集、systemd 部署和 Prometheus 抓取验证。  
`v1.0.0` 支持结论：Exporter 依赖驱动提供的通用 `hy-smi` / `hcu-smi` 命令接口；驱动正常支持目标设备且命令输出保持兼容时，可使用当前采集和解析实现。  
公开矩阵结论：BW100 标记为“历史真机验证通过”，其他驱动支持型号标记为“支持，基于通用命令接口”。  
已知限制：历史 commit、DTK 准确版本、工具准确版本以及节点 B 的驱动/VBIOS 未单独记录；当前候选 commit 未重新进行真机回归。  
发布处理：上述限制在公开兼容性文档和 Release Notes 中披露，不阻止 `v1.0.0` 作为社区版本发布。
