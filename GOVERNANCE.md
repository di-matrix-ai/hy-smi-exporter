# Governance

The project is maintained in the open. Maintainers review pull requests,
triage issues, approve releases, and keep compatibility with supported Hygon
drivers documented.

Routine changes need one maintainer approval and passing CI. Changes affecting
metric names, types, labels, security behavior, or release policy should be
called out explicitly in the pull request and may require review from two
maintainers once the project has multiple active maintainers.

The maintainers listed in `MAINTAINERS.md` may add or remove maintainers based
on sustained contributions, review quality, and willingness to support releases.
