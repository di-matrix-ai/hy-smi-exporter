# 驱动与设备兼容性

本文档说明海光驱动的厂商参考范围，以及 `hy-smi-exporter` 已完成验证的组合。

> 驱动支持某个硬件型号，不等于 exporter 已经验证并承诺支持该型号。对外发布时，只对“exporter 实测兼容矩阵”中的组合做兼容性承诺。

## 1 支持范围说明

`hy-smi-exporter` 通过宿主机已有的 `hy-smi` / `hcu-smi` 只读命令采集设备指标，主要验证以下接口：

- `hy-smi -a --json` 主查询；
- `hy-smi -a` 文本回退查询；
- `hy-smi --showmeminfo all --json` 显存补充查询；
- `hy-smi --showmemavailable --json` 可用显存补充查询。

实际兼容性取决于硬件型号、驱动、固件、DTK、`hy-smi` / `hcu-smi` 版本、Linux 发行版和内核版本的组合。

结果使用以下定义：

- **已验证**：真实设备上完成核心指标、异常路径和稳定性测试；
- **有条件支持**：主要功能可用，但存在已记录的字段缺失、版本限制或部署条件；
- **待验证**：只有厂商资料、代码样例或解析 fixture，尚未完成真实设备回归；
- **不支持**：已确认接口、字段或运行环境不满足当前实现要求。

## 4 验证项目

每个对外标记为“已验证”的组合至少应完成：

- 设备发现和设备数量核对；
- `hy-smi -a --json` JSON 主查询；
- `hy-smi -a` 文本回退；
- 显存主查询或补充查询；
- 温度、功耗、利用率和时钟；
- 显存、PCIe、链路、健康、RAS、ECC 和坏页；
- 单卡和多卡；
- 驱动未加载、命令失败、命令超时、权限不足和字段缺失；
- `/healthz`、`/metrics` 和 Prometheus 抓取；
- 至少 30 分钟连续运行，以及 15 秒或 30 秒抓取周期稳定性；
- 单次采集耗时、CPU、内存和抓取成功率记录。

## 5 版本升级要求

设备、驱动、固件、DTK 或 `hy-smi` / `hcu-smi` 升级后，应重新执行兼容性回归。重点检查：

- JSON 字段名称、层级和字段类型；
- 文本输出的标题、单位和列顺序；
- 显存单位及 `available` 字段定义；
- 温度、功耗、利用率和带宽单位；
- RAS、ECC 和坏页计数是否仍为累计值；
- 健康状态、工作模式和链路状态枚举；
- 设备身份信息和标签字段是否发生变化。

升级前后的命令输出应保留脱敏样例，出现字段变化时补充解析 fixture、单元测试和变更记录。

## 6 容器范围说明

`v0.1.0` 不兼容、不测试、不发布 Docker、Docker Compose、Kubernetes 和容器镜像。海光资料中关于 6.3.x 驱动和 `/sys/kernel/debug` 的容器说明保留在参考文档中，后续纳入容器支持时再单独验证。

## 7 已知边界

- 本项目不分发海光驱动、固件或 `hy-smi` / `hcu-smi` 二进制；
- 厂商驱动兼容表不是 exporter 兼容承诺；
- 未经真实设备测试的型号和驱动组合只能标记为“待验证”；
- 指标字段缺失或工具输出变化时，可能导致部分指标不输出；
- 生产环境应限制 `/metrics` 访问，并避免公开序列号、Unique ID、主机名和 PCIe 地址。
